# Autoresearch Idea Seeds

These are conceptual starting points to inspire your own pipeline. None of these are pre-built - they're ideas for what you can build with your Claude agent during setup.

---

**Cold Email Reply Rate**
Optimize email copy (subject line, body, CTA) to maximize reply rate. Measure via your email platform's API (Instantly, Lemlist, Smartlead). Deploy by creating new campaigns via API. Measurement window: 24-48 hours per experiment.

**Landing Page Conversion**
Optimize page copy, layout, headlines, and CTAs to maximize signup/conversion rate. Measure via analytics (PostHog, GA4, Plausible). Deploy via git push to Vercel/Netlify or CMS API. Measurement window: 6-24 hours depending on traffic.

**Ad Creative Performance**
Optimize ad copy, headlines, and descriptions to maximize click-through rate. Measure via ad platform API (Facebook Ads, Google Ads). Deploy by creating new ad variants via API. Measurement window: 6-24 hours depending on spend.

**Newsletter Subject Lines**
Optimize email subject lines and preview text to maximize open rate. Measure via email platform API (ConvertKit, Beehiiv, Mailchimp). Deploy by scheduling sends via API. Measurement window: 24 hours per send.

**Pricing Page Optimization**
Optimize pricing copy, tier names, feature descriptions, and layout to maximize checkout start rate. Measure via Stripe API + analytics. Deploy via git push or CMS API. Measurement window: 24-48 hours.

**YouTube Thumbnail CTR**
Optimize thumbnail design prompts or compositions to maximize click-through rate. Measure via YouTube Data API v3. Deploy by updating thumbnails via API or manually. Measurement window: 48 hours.

**Chatbot Script Optimization**
Optimize chatbot system prompt and response templates to maximize customer satisfaction score (CSAT). Measure via survey endpoint or support platform API. Deploy by updating the system prompt. Measurement window: 4-12 hours depending on conversation volume.

**Product Description Optimization**
Optimize ecommerce product descriptions to maximize conversion rate or revenue per visitor. Measure via Shopify API + analytics. Deploy by updating product descriptions via API. Measurement window: 24-48 hours.

**Social Media Post Engagement**
Optimize post copy, format, and hooks to maximize engagement rate (likes/reach or comments/reach). Measure via platform API (Twitter/X, LinkedIn, Instagram). Deploy by scheduling posts via API. Measurement window: 24-48 hours.

**SEO Title/Meta Optimization**
Optimize page titles and meta descriptions to maximize click-through rate from search results. Measure via Google Search Console API. Deploy via CMS API or git push. Measurement window: 7-14 days (SEO is slow).

**Outreach DM Templates**
Optimize direct message templates for platforms like Instagram, LinkedIn, or TikTok to maximize reply rate. Measure by tracking replies manually or via platform API. Deploy by updating the template file. Measurement window: 24-48 hours.

**Webinar/Call Registration Page**
Optimize registration page copy and layout to maximize signup rate. Measure via form submission tracking (analytics or CRM API). Deploy via landing page platform. Measurement window: 24-48 hours depending on traffic.
