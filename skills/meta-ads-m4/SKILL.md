# Meta Ads — The M4 Method

Four sequential phases. Do NOT skip forward. M1 and M2 are non-optional foundations; M3 compounds small wins; M4 is only for stable accounts > $30K/month with 90+ days of M1/M2 discipline.

## Phase 1 — Campaign Structure (Swimlanes)

Organize every account into separate campaigns by audience temperature. Cold and warm must never blend into one ROAS number.

- **Prospecting** — 100% net-new, broad + single-interest, excludes retargeting/retention
- **Retention** — existing customers, segmented by purchase history
- **Retargeting** (optional) — site visitors, ATC, engagers
- **Scale** (optional) — graduated top performers, broad audience only

**Rules:**
- Default to CBO (Campaign Budget Optimization), not ABO
- Never stack interests — test ONE interest per ad set
- Lookalikes only if historically validated
- Configure audience-level exclusions between swimlanes
- **Always optimize for Sales objective, never Traffic.** Switching Traffic→Sales typically delivers a 20–30% day-one lift.

## Phase 2 — Andromeda Creative System

Post-Andromeda, creative IS the targeting. Every winning ad contains four components:

1. **Avatar** — the specific person being addressed
2. **Education** — problem identification
3. **Mechanism** — how the solution works
4. **Offer** — value, timing, risk

**Creative packs:** Launch 4–8 ads per pack. Wait 7 days if spend > $1K/day, 14 days if under.

**Pack management:**
| Spend | Performance | Action |
|---|---|---|
| High | High | Graduate to scale |
| High | Low | Pause (bad conversions) |
| Low | Low | Pause |
| Average | Average | Leave untouched |

**80/20 iteration rule:** 80% of effort on variations of winners (background, model, expression, text, color, positioning); 20% on researched new concepts.

**Flywheel:** Launch → Analyze (7–14d) → Identify winners (top-spend, hitting KPI) → Iterate → Competitive research (Facebook Ad Library) → back to Launch.

Target: **beat baseline conversions by 2–5% week-over-week.**

**Never cherry-pick low-spend high-ROAS ads** — if they were real winners, the algorithm would allocate more budget.

## Phase 3 — Fastest Horse (Breakdowns)

Most advertisers spend identically every day. Reallocate based on actual variance. Run breakdowns in this order and stack the wins:

1. Placement (Feed, Reels, Stories)
2. Platform (Facebook vs Instagram)
3. Age
4. Gender
5. Age × Gender (hyper-specific)
6. Landing page (URL-level)
7. Country

Each breakdown typically yields 3–5%. **Stack 5 tests = 25–50% ROAS lift**, which usually unlocks 5–10× scaling headroom. Also run day-of-week and time-of-day; reallocate away from slow horses.

## Phase 4 — Cost Caps (Advanced)

**Prerequisites (all required):**
- 90+ days of M1/M2 stability
- $30K+/month spend
- Strong historical baseline

Premature cost caps halt spend, cause uneven ad-set allocation, and drift above targets. Most advertisers default to Highest Volume; graduates move to cost caps only after foundational stability.

## Measurement Rules

- **Never report blended ROAS** — always break out Prospecting / Retargeting / Retention
- **Monitor frequency** — overspending wrong cohorts is the silent killer
- **Attribute to learning, not luck** — winners must meet structured criteria, not vibes

## Checklist Before Scaling Any Account

- [ ] Swimlanes separated with proper exclusions
- [ ] CBO on every campaign
- [ ] Sales objective (never Traffic)
- [ ] Single interest per ad set
- [ ] Ad packs of 4–8 launched with 7/14-day analysis windows
- [ ] Creative pack management table followed (no pausing high-spend winners)
- [ ] Weekly 2–5% conversion lift targeted
- [ ] At least 3 breakdown dimensions analyzed before scaling spend
- [ ] ROAS reported by swimlane, not blended
- [ ] Cost caps OFF unless all four prerequisites met
